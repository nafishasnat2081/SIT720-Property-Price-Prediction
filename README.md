 SIT720 Property Price Prediction

 Project Overview

This project develops a machine learning-based residential property price prediction system using Sydney housing market data.

The project implements a complete machine learning workflow including:

- Data collection
- Data preprocessing
- Exploratory data analysis
- Feature engineering
- Regression model development
- Model evaluation
- Model deployment using Streamlit


 Dataset

The dataset was manually collected from publicly available real estate sources.

The selected Sydney suburbs are:

- Surry Hills
- Greater Parramatta
- Campbelltown

The dataset contains property features including:

- Property type
- Market region
- Bedrooms
- Bathrooms
- Car spaces
- Building size
- Sale month
- Sale year
- Total rooms
- Price per square metre
- Sale price (target variable)


Machine Learning Models

Three regression models were developed:

1. Linear Regression
2. Random Forest Regression
3. Gradient Boosting Regression

Random Forest Regression was selected as the final deployed model based on cross-validation performance.




Deployment

The final Random Forest model was deployed using Streamlit.

Users can enter property characteristics through the web interface and receive an estimated property sale price prediction.


Reproducibility

The repository contains the required dataset, notebook, source code, and supporting files required to reproduce the project results.
